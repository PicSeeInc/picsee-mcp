# Security Policy

## Reporting a vulnerability

Please do not disclose security vulnerabilities through public GitHub issues.

Report vulnerabilities to **service@picsee.vip** with:

- A clear description of the issue and potential impact.
- Reproduction steps or a minimal proof of concept.
- Affected endpoint, tool, or version.
- Any suggested remediation, if available.

Do not include real user access tokens, refresh tokens, private links, or analytics data. Use test accounts and sanitized examples whenever possible.

We will acknowledge receipt as soon as possible, investigate the report, and coordinate disclosure after a fix is available.

## Supported versions

The hosted MCP endpoint is continuously updated. Only the current production version listed as latest in the Official MCP Registry is supported.
